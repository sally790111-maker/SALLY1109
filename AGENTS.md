# Repository Guidelines

## Current State

This repository is currently empty. Update this file when the project language,
framework, build system, and test commands are known.

## Working Agreement

- Keep changes focused on the requested task.
- Preserve user-authored and unrelated changes in the working tree.
- Prefer small, reviewable edits over broad rewrites.
- Do not commit secrets, credentials, generated dependency folders, or local
  environment files.
- Add or update tests when behavior changes.
- Run the most relevant available checks before handing off work.

## Project Structure

- Keep source code, tests, documentation, and generated output clearly
  separated.
- Follow conventions already established by the project once files exist.
- Add project-specific commands and architecture notes here as the repository
  takes shape.

## Git

- Use the `codex/` prefix for branches created by Codex unless instructed
  otherwise.
- Write concise commit messages that describe the outcome of the change.
- Never discard or overwrite existing work without explicit authorization.
